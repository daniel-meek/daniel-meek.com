Feature-Reduced Machine Learning for On-Device Anomaly Detection in Resource-Constrained IoT Networks

D. L. Meek & B. Haskins (2026) · Presented at ARTIIS 2026.

Intrusion detection on resource-constrained IoT devices faces a tight trade-off: rich network flow datasets contain dozens of statistical features, but edge hardware rarely has the memory or CPU budget to extract and evaluate all of them in real time.

In this paper—co-authored with B. Haskins and presented at ARTIIS 2026—we investigate how Recursive Feature Elimination (RFE) can shrink machine learning models for on-device anomaly detection without sacrificing detection performance, evaluated on the CIC IoT-DIAD 2024 dataset.

Key Focus Areas

  • Feature Reduction via RFE

    Systematically pruning redundant network flow features to lower inference overhead and memory footprint.

  • On-Device Feasibility

    Benchmarking reduced models against the constraints of real-world edge hardware rather than cloud-only accuracy metrics.
